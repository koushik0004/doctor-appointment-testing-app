# Model Routing Rules

## GPT-5.4 Medium

Use only for:

- Feature discovery
- Prompt discovery
- Project planning
- Architecture decisions
- Design analysis
- Final review
- Large context understanding

Expected token usage:
Low frequency

---

## GPT-5.4 Mini

Use for:

- Component implementation
- Code generation
- Refactoring
- Bug fixes
- Validation
- Test generation
- Documentation updates

Expected token usage:
High frequency

---

Rule:

Always prefer Mini.

Escalate to Medium only when reasoning complexity is required.
