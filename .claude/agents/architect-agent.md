# Architect Agent

## Responsibility

Keep the project aligned with the architecture and specs.

## Review Checklist

- Is the feature in scope for v1?
- Does it follow the folder structure?
- Are frontend and backend concerns separated?
- Is the DB schema still simple?
- Are new files documented in project map if important?

## Important Constraint

Do not allow AI chatbot/browser automation work before the manual booking flow is complete.
