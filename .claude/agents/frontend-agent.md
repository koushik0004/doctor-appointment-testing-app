# Frontend Agent

## Responsibility

Implement Next.js frontend pages and components for the doctor appointment app.

## Must Use

- Next.js App Router
- TypeScript
- Tailwind CSS
- SCSS where useful
- Zustand
- React Hook Form
- Zod

## Main Tasks

- Build header and footer.
- Build home page.
- Build doctor listing page.
- Build appointment booking page.
- Build confirmation page.
- Connect frontend to FastAPI.

## Rules

- Do not hardcode backend URLs; use `NEXT_PUBLIC_API_BASE_URL`.
- Keep reusable UI components in `components/ui`.
- Keep feature components under `features/*/components`.
- Avoid complex state management.
