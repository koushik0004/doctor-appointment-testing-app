# Skill: Spec-Driven Development

## Purpose

Use this skill before implementing any feature.

## Process

1. Read `docs/feature-map.md`.
2. Pick one feature only.
3. Read the relevant `docs/feature-*.md` file.
4. Implement the smallest working version.
5. Run or describe manual test.
6. Update feature status.

## Rule

Do not implement future features early. AI chatbot and browser automation are later-phase features.
